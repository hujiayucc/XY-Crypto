# 个人信息收集清单

版本：2.0
更新日期：2026/10/07
生效日期：2022/10/25
个人信息处理者：胡佳宇
联系邮箱：hujiayucc@qq.com

本清单说明功能涉及的信息类型，不是用户操作日志；未触发相应功能时不产生该项业务处理。文本、图片可能包含个人信息，本地处理也属于信息处理，不等于零收集。

| 功能与信息类型 | 目的、方式和触发条件 | 保存位置、期限及删除方式 |
|---|---|---|
| 文本编码、加解密、摘要、派生、签名：输入文本、密钥、参数及输出 | 用户输入或导入后在本机计算；不向运营者服务器上传 | 当前会话内存；清空输入/输出、撤回同意或进程结束时释放；内存释放不等于物理安全擦除 |
| 记住密钥：密码和密钥 JSON | 仅主动勾选记住后保存在本机；新输入默认不勾选 | 平台安全存储，保留到用户清除或平台清理；菜单“清除本机已保存密钥”删除五类密钥槽位；取消勾选只是不保存本次新值，不删除旧值 |
| 导入文件及图片：所选文件内容、文件名、路径/临时 URI | 点击文件选择器后仅读取所选项目；图片以 image 和 zxing2 本地解码 | 内存及选择器可能创建的应用私有缓存；缓存随平台清理，Android 可通过系统清除缓存移除；源文件由用户自行删除 |
| 相机画面和二维码结果 | 用户确认扫码说明且相机获准后处理；图像在设备识别，不录制视频 | 扫描期间内存；退出扫描页结束画面处理；结果导入当前会话 |
| 剪贴板文本 | 用户主动点击导入或使用系统粘贴功能时读取；复制功能写入用户选定的内容 | 导入内容进入会话；系统剪贴板副本由系统/用户管理，不自动定时读取 |
| 外部分享：链接、文本、可选密钥 | 操作系统按用户选择将内容交给应用；同意政策后才由应用业务层解析 | 待处理 Intent 由操作系统投递；应用解析后清空 Intent，结果进入会话；拒绝/撤回不解析并清空 |
| 同意记录：政策版本和 UTC 确认时间 | 决定是否展示新版本确认框，无设备标识；Android 使用应用私有配置 | 本机；撤回删除；旧版本不视为新版本同意 |
| 相机权限拒绝时间 | Android 记录最近一次拒绝时刻，避免 48 小时内重复弹系统请求；启动时不申请 | 应用私有配置，下一次拒绝覆盖；清除应用数据移除，不用于画像 |
| ML Kit 诊断信息：制造商、型号、系统版本/build、硬件加速器信息、包名/版本、每次安装标识符、延迟、API 配置、输入输出大小、功能版本、事件及错误码 | Android 相机扫码使用捆绑模型；Google 官方披露这些信息用于诊断和使用情况分析，经 HTTPS 传输。不是输入文本或图像内容上传 | Google 按其条款处理；官方数据披露页未承诺本应用可设置的固定保存天数。准确接收地点、期限及权利响应须发布方核验，详见共享清单 |
| 网页访问信息（仅主动进入网页功能时） | 目标站点接收请求 URL、IP、浏览器/系统信息及你提交的内容，可能设置 Cookie | 系统 WebView 或外部浏览器、目标站点；应用内网页菜单可清缓存/本地存储，Cookie/外部浏览器副本按系统与站点设置处理 |

本应用无账号、广告、定向推送、位置、通讯录、短信、电话和麦克风业务。应用自身代码没有读取 IMEI、IMSI、OAID、Android ID、MAC、BSSID、SSID 或设备软件安装列表的业务调用；该表述不排除上列 SDK 的每次安装标识符和诊断信息。
