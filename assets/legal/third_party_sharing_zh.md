开源组件参与本机运算不等于向其开发者发送数据。以下分别说明独立 SDK 接收方、用户选择的分享目标与系统能力；完整组件名单见“第三方 SDK 与组件清单”。

| 接收方/联系方式 | 信息类型和共享方式 | 目的、触发条件和控制 |
|---|---|---|
| Google LLC，ML Kit；隐私联系入口 https://policies.google.com/privacy | 设备型号、厂商、系统/build、硬件加速器、包名/版本、每次安装标识符、性能/配置/事件/错误信息；SDK 经 HTTPS 发送；图像识别在本地 | 诊断和使用情况分析。Android 用户选择“同意并使用相机”且权限获准后才初始化；选择图片识别不启用 ML Kit。撤回政策同意后退出进程以停止 SDK 后续工作 |
| 用户在系统分享面板中选择的接收应用及其服务提供者；以选择界面的身份与其隐私政策为准 | 选定文本、密文、链接或二维码所表达的内容；主动包含密钥时同传密钥 | 用户逐次发起分享、复制或展示二维码。默认不携带密钥；含密钥链接的持有者可读取密钥并解密。第三方已取得的副本需向相应接收方删除 |
| 用户访问的网站、外部浏览器及其运营者；以目标域名/站点隐私政策为准 | IP、请求地址、浏览器信息、Cookie、用户提交内容；网络访问产生 | 仅主动使用网页或外部链接时；关闭页面停止后续访问，已提交内容按站点规则处理 |
| 操作系统、文件选择器、安全存储与系统分享能力的提供者 | 所选文件/URI、用户交给系统的剪贴板/分享内容、密钥安全存储等 | 提供用户发起的本机功能；不是向插件作者自动上传，系统备份/诊断等按系统设置管理 |

## Google ML Kit 官方规则

Android 数据披露：https://developers.google.cn/ml-kit/android-data-disclosure?hl=zh-cn
条款与隐私：https://developers.google.cn/ml-kit/terms
Google 隐私政策及联系：https://policies.google.com/privacy

官方披露页描述 SDK 最新版本，不替代对本项目锁定版本及发行包的动态核验。Google 的 SDK 数据保存期限、接收地点及可能的境外处理，需要运营主体在正式发布前查证并完成适用手续；当前开发预览版的说明不构成“已完成跨境合规”的结论。用户可选择不启用相机扫码而使用本地图片识别。
