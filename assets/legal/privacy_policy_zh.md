本文件为开发预览版；ML Kit 境外处理资料待补齐和核验后正式发布。本政策及下列清单说明本应用对个人信息的处理方式，不作平台审核通过承诺。

## 1. 适用范围与核心功能

XY加密（Android 包名 com.hujiayucc.decode）提供本机文本编码、摘要、派生、加解密和签名。应用没有账号、广告、个性化推荐、定向推送或云同步服务。运营者未建设接收文本和密钥的业务服务器；这不表示所有第三方 SDK 都不传输信息。

相机扫码使用的 Google ML Kit 有官方披露的诊断和使用情况分析数据，包括每次安装标识符。具体种类、目的、传输方式、第三方身份与控制见本政策附录，用户也可选择无需该 SDK 的本地图片识别。

## 2. 告知、同意与按需处理

首次启动在启动页上展示协议弹窗，同意框默认未勾选。阅读文档不等于同意；仅主动勾选并点击“同意并继续”后保存政策版本、UTC 时间并启用业务。选择“退出应用”结束 Android 应用。Android 在确认前不注册可选 Flutter 业务插件，不解析外部分享文本/链接，移除了 ML Kit 的自动初始化 Provider。

非必要权限在具体场景单独申请，政策同意不代替系统权限或扫码 SDK 提示。拒绝相机、取消选择文件或取消分享均不影响本地加解密。政策处理范围变更时提高版本号并重新提示。

## 3. 本地处理与密钥安全存储

输入、结果和本次密钥通常在会话内存中处理。密钥输入默认不记住；用户主动勾选后写入本机平台安全存储。再次取消勾选只影响本次保存，已有密钥需通过“清除本机已保存密钥”删除。密钥槽位按算法家族共用，加密可读取此前保存的对应密钥，解密操作仍由用户确认输入。

安全存储的保护能力依赖平台和锁屏配置，不保证丢失密钥恢复或物理内存安全擦除。Android 关闭系统自动备份开关；设备迁移、第三方备份及系统安全存储的保留行为仍受系统机制影响。

## 4. 敏感内容与对外提供

请仅输入功能所需的信息。文本、文件或图片可能含有身份、财产、健康等敏感个人信息；用户应审慎选择，应用不主动要求这些信息。相机图像为扫码所需，在设备识别。密钥、明文及含密钥的分享链接属于需要重点保护的秘密。

系统分享、复制和二维码由用户逐次发起；默认不携带密钥。勾选包含密钥后，密钥以链接参数形式与密文一同交给所选渠道，取得链接的人可能直接解密。已被第三方取得的副本需通过对应接收方处理，撤回本应用同意不自动撤回已发送内容。

## 5. 保存期限、存储与境外处理

会话内容保留至清空、撤回或进程结束；记住的密钥保留至主动清除或平台清理；文件选择器可能生成临时缓存。各类期限和删除路径详见个人信息清单。

ML Kit 诊断由 Google 按其隐私规则处理。其公开披露没有给出本应用可配置的固定保存天数，接收地点、境外处理与适用程序需运营主体核实后再发行；本预览版不将“SDK 使用 HTTPS”解释为已完成相关手续。用户可不启用相机扫码，继续使用本地算法和图片识别。用户访问的境外网站或第三方分享目标还按对应服务规则处理。

## 6. 用户权利与操作路径

查阅和复制：菜单 → 隐私政策，或菜单 → 隐私中心 → 各清单；正文支持文本选择复制。输入/输出可自行查阅、修改、复制和清空。账户注销：本版本无账号系统，无账号注销对象。

删除：菜单 → 清除本机已保存密钥；输入和输出分别清空；文件源副本由你删除；缓存可在 Android 系统应用设置中清除。清除本机密钥只删除五类密钥槽位，不删除政策同意记录，也不删除对外分享副本。

撤回：菜单 → 撤回协议同意 → 确认。删除确认记录、清空会话并退出 Android 应用，终止当前进程的可选 SDK 工作；下次启动重新确认。撤回不影响撤回前基于有效同意的处理；已保存密钥可先单独清除。

权限：菜单 → 隐私中心 → 系统权限管理。相机权限可在系统撤销。无个性化推荐/广告/定向推送功能，因此没有虚设开关。查阅、更正、复制、删除、限制处理及投诉可通过下方隐私邮箱提出；正式运营后在收到请求起 15 个工作日内核验并答复，法律另有要求从其规定。身份核验限于处理请求必要信息，不索取加密密钥或无关身份资料。

## 7. 未成年人和安全

未成年人请在监护人指导下使用；不满十四周岁的用户应由监护人阅读并作出必要决定。本应用非面向儿童的服务，不要求提交年龄或身份证。监护人可通过下方渠道咨询本机数据删除及权利请求。

采用本地计算、按需权限、平台存储、SDK 延迟初始化等措施，并持续检查依赖。任何软件和设备都存在风险；发生信息安全事件时将按适用规定处置和告知，避免在日志中输出明文、密钥或分享链接。

## 管理路径

首页菜单 → 隐私中心 → 系统权限管理（3 次操作到系统设置入口），再按系统界面选择相机等权限。桌面系统按各自的系统设置管理；不同设备的设置名称可能不同。

应用没有短信、电话、通讯录、位置、录音、后台定位或广告标识权限用途。正式签名包的最终合并清单仍应逐项核查，不将开发包的检查替代发行包验收。
